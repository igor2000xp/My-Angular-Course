# Project Brief

## Project Name
Angular Course 2025 (Базовый курс по Angular)

## Project Type
Educational Angular Course Project

## Core Purpose
A comprehensive Angular tutorial course covering fundamental to advanced concepts for Angular v16+ (currently on v19). The project serves as both learning material and practical implementation examples for Russian-speaking Angular developers.

## Primary Goals
1. Provide hands-on examples for 45+ Angular topics
2. Demonstrate best practices for Angular development
3. Cover the complete Angular ecosystem (components, services, forms, RxJS, etc.)
4. Maintain up-to-date examples with latest Angular versions

## Target Audience
Russian-speaking developers learning Angular framework

## Success Criteria
- Complete implementation of all course topics
- Working examples for each concept
- Clean, maintainable code following Angular best practices
- Regular updates to match new Angular versions

## Current Focus
Template-driven forms with validation and RxJS integration (Branch: my/47-templ-forms-pract)
